# Day 4: Git Commit Message Practice

Practiced writing professional commit messages using the required course format.

**Format used:**
- `Add:`
- `Fix:`
- `Update:`
- `Style:`
- `Docs:`
- `Remove:`
- `Refactor:`

**Examples of commits I made:**
- `Style: add navigation hover underline`
- `Docs: add terminal log`
- `Add: project setup shell script`
- `Fix: resolve merge conflict in about.html`
- `Update: improve about page content`
- `Add: daily challenges day 1 and day 2`
- `Add: day 3 HTML boilerplate script`
